# 🎮 Video Game Sales & Engagement Analysis

## 📌 Project Overview
This project analyzes video game sales and engagement metrics to uncover trends in:

- Genre popularity
- Platform performance
- Wishlist and rating impact on sales

## 🚀 Tech Stack
- Python (Pandas, Matplotlib)
- SQL (MySQL)
- Power BI Dashboard
- Streamlit App

## 📂 Dataset
- games.csv → Engagement Data
- vgsales.csv → Regional Sales Data

## 📊 Key Insights
- Top genres generating maximum revenue
- Rating vs Sales relationship
- Wishlist impact on demand forecasting

## 📌 Deliverables
✅ Clean SQL Database  
✅ Interactive Power BI Dashboard  
✅ Streamlit Web Dashboard  
✅ Full EDA Notebook
